== 2026-05-08 -- Session 1

*Goal:* Build M0-M3 of TAO-Scout end to end. Wire AsciiDoc docs and ICM
workspace scaffold per user clarification.

*Done:*

* M0: `pyproject.toml` with pinned deps, package layout, `.env.example`,
  `.gitignore`.
* `safety.py` with `FORBIDDEN_SDK_METHODS` deny-list, `assert_read_only_call`,
  `find_forbidden_wallet_imports` AST scan, `warn_if_wallet_env_present`.
* `config.py` with frozen `read_only=True` (Pydantic v2 `frozen=True`,
  validator rejects override).
* SQLAlchemy 2.x async models for `Subnet`, `Note`, `Score`, `Snapshot`,
  `UserSettings`. Alembic baseline migration.
* M1: `chain/client.py` (AsyncSubtensor wrapper) with both deny-list and
  allow-list. `chain/cache.py` with TTL + stale-while-error fallback.
* M2: scoring engine (six axes, weighted total, rationale skeleton),
  service layer (notes upsert, scores append-only, rank, settings), ICM
  workspace scaffold under `data/workspaces/netuid-NNN/`.
* M3: HTTP API (subnets, notes, scores, rank, settings, export, import,
  health). HTMX web UI (subnet list with Continue rail, subnet detail,
  rank, settings).
* CLI: `list`, `show`, `refresh`, `note add/edit`, `score`, `rank`,
  `export`, `import`, `serve`, `doctor`.
* Tests: `test_safety.py` (incl. AST scan + deny-list parametrized),
  `test_scoring.py` (math + append-only), `test_cache.py` (TTL +
  stale-while-error), `test_services.py` (notes, rank, settings, ICM
  workspaces, Continue rail), `test_api.py` (full HTTP flow).
* Docs in AsciiDoc: `README.adoc`, `CLAUDE.adoc`, `ROADMAP.adoc`,
  `RUN_LOG.adoc`.

*Decisions:*

* AsciiDoc adopted for top-level docs from M0 (user request).
* ICM workspaces scaffolded eagerly when the user opens a subnet detail
  page; Continue rail surfaces missing stages.
* No background polling, no daemon mode, foreground `tao-scout serve`
  only -- per spec section 7 and explicit user confirmation.

*Blocked:* none.

*SDK version:* tracked at runtime via `tao-scout doctor`.

== 2026-05-08 -- Session 2 (audit + polish)

*Goal:* Audit the M0-M3 implementation against `CLAUDE.adoc` and bring it
to a clean v1 state.

*Done:*

* Audit pass over the full repo. Read-only invariants verified
  end-to-end (deny-list, allow-list, AST wallet-import scan, frozen
  `Settings.read_only`).
* Safety: extended `FORBIDDEN_SDK_METHODS` with `set_root_weights`,
  `commit_reveal_weights`, `pow_register`, `submit_extrinsic`,
  `compose_call`, `add_stake_multiple`, `remove_stake_multiple`,
  `unstake_all`, `register_subnet`, `sudo_set`, `set_subnet_identity`,
  and a few sign/transfer aliases.
* Self-audit: `_self_audit` now scans the whole `src/` tree (one level
  above the package) instead of only the package directory.
* Tests: added `test_settings_explicit_false_kwarg_is_rejected`,
  `test_settings_frozen_blocks_reassignment`, and
  `test_deny_list_covers_known_dangerous_methods`. Added snapshot
  service tests and an `append_score`-no-side-effect regression test.
* M3 closure: `tao-scout snapshot` command + `services.capture_snapshot`
  + `services.list_snapshots`. Supports single, `--all`, and `--list`.
* Service-layer correctness: `append_score` no longer creates a
  `UserSettings` row as a write side-effect of scoring — it reads the
  existing row if present, otherwise falls back to `DEFAULT_WEIGHTS`.
* Web UI: `submit_note` now requires the subnet to be in the cache
  (symmetric with the API). `/refresh` now redirects to home with a
  query-string flash (`msg=...&kind=ok|error`) so RPC failures surface
  visibly.
* CLI polish: `tao-scout export --format csv` now writes CSV to disk
  (was previously web-only). `Optional[X]` replaced by `X | None`.
  Removed dead `typer.prompt("netuid")` branch in interactive note
  flow. Doctor message hints `alembic upgrade head` on DB failure.
* Tooling: per-file ruff ignores for FastAPI/Typer `Depends`/`Option`
  defaults, `Jinja2Templates` forward-ref, `AsyncSubtensor` casing.
* End-to-end verification: `pytest` 89/89 green, `ruff check` clean,
  `tao-scout doctor` reaches a live finney RPC (block returned) and
  reports all six checks OK.

*Decisions:*

* Did not add list filters, sparklines, or README screenshots — those
  remain on the M4 roadmap.
* CSV export is now symmetric across CLI and web; CSV import is still
  out of scope (JSON only) per spec.
* Refresh feedback uses redirect-with-query-string rather than
  cookies/sessions to keep the app stateless.

*Blocked:* none.

*Next:* M4 list filters, score-history sparklines, README screenshots.
